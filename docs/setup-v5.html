RealizeOS V5 Quickstart

Get the core system running on your local machine in under 5 minutes.

Before you begin

Ensure you have Node.js 20+, Git, and optionally Docker installed on your system. You will also need API keys from Anthropic (Claude) and/or OpenAI to power the FABRIC AI agents.

1

Initialize the Project

Choose your preferred installation method below to bootstrap the RealizeOS V5 environment.

The easiest way to start a new RealizeOS project is via our CLI.

npx @realize-os/cli init my-realize-os
cd my-realize-os

Alternatively, clone the repository directly and install dependencies.

git clone https://github.com/RealizeOS/RealizeOS-5.git
cd RealizeOS-5
npm install

If you prefer containerization, use our pre-built Docker setup.

git clone https://github.com/RealizeOS/RealizeOS-5.git
cd RealizeOS-5
docker-compose up -d
2

Configure APIs

RealizeOS requires LLM API keys to power the multi-agent routing. Copy the example environment file and add your keys.

cp .env.example .env

Open .env in your favorite editor and populate the following essential variables:

# Required for optimal Multi-LLM routing
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-...

# Database Configuration (SQLite default)
DATABASE_URL="file:./dev.db"
3

Start the Development Server

With your environment configured and dependencies installed, you're ready to boot the system.

npm run dev

The RealizeOS dashboard will typically be available at http://localhost:5173. The backend API runs on http://localhost:3000.
