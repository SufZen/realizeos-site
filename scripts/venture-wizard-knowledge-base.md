## What is RealizeOS?
RealizeOS is an open-source AI operations engine that lets you deploy a team of specialized AI agents on your own infrastructure. Unlike generic chatbots, RealizeOS agents share a persistent knowledge base, follow your business rules, and work together on multi-step workflows.

- Website: https://sufzen.github.io/realizeos-site/

## The FABRIC Architecture
FABRIC is the knowledge structure at the heart of RealizeOS. It has 6 layers:

### F — Foundations
System methodology, venture identity, voice rules, and business rules that every agent follows. This is where the 3 files generated by the Venture Wizard live:
- `shared/identity.md` — Who you are as a person
- `systems/<venture>/F-foundations/venture-identity.md` — Business positioning
- `systems/<venture>/F-foundations/venture-voice.md` — Voice & tone rules

### A — Agents
Your specialized AI team. Each agent has a role (writer, analyst, reviewer, orchestrator), a model assignment, and a set of skills. Agents are defined in `realize-os.yaml`.

### B — Brain
Domain knowledge your team remembers across conversations. Market data, expertise, deal history, meeting notes — stored in the Synapse knowledge index with hybrid search (keyword + semantic via FTS5 + vector embeddings).

### R — Routines
Workflows that chain agents and tools together. Example: "Draft project narrative" triggers the writer agent, then automatically passes the output to the reviewer agent.

### I — Insights
A learning log that makes your team smarter over time. The Dreaming subsystem processes daily interactions and suggests improvements. The Trust Policy scores each proposal before applying it.

### C — Creations
Organized, reviewable outputs. Every deliverable lands in a structured format that can be reviewed, versioned, and deployed.

## Complete File Structure
```
shared/
  identity.md              ← Who you are (personal, shared across ventures)
systems/
  my-venture-1/
    F-foundations/
      venture-identity.md   ← Business positioning & strategy
      venture-voice.md      ← Voice, tone, and content rules
    A-agents/               ← Agent role definitions
    B-brain/                ← Knowledge documents, market data
    R-routines/             ← Workflow definitions
    I-insights/             ← Learning logs, dreaming proposals
    C-creations/            ← Generated outputs & deliverables
  my-venture-2/             ← Each venture gets its own FABRIC
    F-foundations/
    A-agents/
    ...
```

## Key Technical Components

### FABRIC Entity System
Stores all venture knowledge as structured entities with typed relationships. Full REST API for CRUD operations. SQLite-backed with FTS5 full-text search.

### Synapse Knowledge Index
Hybrid search across the entire knowledge base — keyword + semantic. Millisecond retrieval. AI agents find the exact right document every time.

### Multi-LLM Routing
Runtime Adapter Layer with provider-agnostic routing. Supports Claude, Gemini, GPT, Ollama (local), and any LLM backend. Per-call cost tracking and intelligent model selection.

### Mission Engine
Full mission lifecycle: define → plan → execute → review → complete. Multi-step workflows with human review gates. Dashboard at `/missions`.

### Dreaming & Trust Policy
Background reflection and continuous improvement. The system processes daily interactions and suggests improvements. Trust Policy scores each proposal. Dashboard at `/dreams`.

### Event Log & SOUL Identity
Full audit trail of every action. Venture identity (SOUL) encoded and versioned. Stores venture voice, methodology, and rules as versionable artifacts.

### FABRIC Operator CLI
Python CLI with `init`, `serve`, `bot`, `status`, and `index` commands. Docker Compose integration. GitHub Actions CI/CD templates.

## Installation Methods
1. **NPX (Recommended)**: `npx @realize-os/cli init my-business && cd my-business && npx @realize-os/cli start`
2. **Docker**: `docker run -d -p 8080:8080 -v realizeos-data:/app/data ghcr.io/sufzen/realizeos:latest`
3. **Python**: `pip install realize-os && realize-os init --template consulting && realize-os serve`
4. **Linux/Mac**: `curl -fsSL https://raw.githubusercontent.com/SufZen/RealizeOS-5/main/scripts/install.sh | bash`
5. **Windows**: `irm https://raw.githubusercontent.com/SufZen/RealizeOS-5/main/scripts/install.ps1 | iex`

- Engineering & operations (project tracking, SOPs, site reports)
